Spring Boot

Spring Boot は「設定より規約」で、動くサーバーを素早く組み立てる

自動構成

  • クラスパスにあるライブラリを見て Bean と設定を自動で用意する
  • 入口は @SpringBootApplication

DI、つまり依存性注入

  • Spring がオブジェクトを生成し、コンストラクタの型に合う実装を渡す
  • このアプリでは Controller に Interactor が渡される

スターターと組み込みサーバー

spring-boot-starter-* で依存をまとめて追加し、Web サーバーを内蔵して ./gradlew bootRun だけで起動する

外部化設定

接続先などは application.yml に出し、コードに埋め込まない
Spring の DI コンテナは「実装を外から渡す」仕組みなので、クリーンアーキテクチャの依存性逆転 DIP と相性が良い

  val created = createTransactionUseCase
      .execute(request.toUseCaseInput())
  return TransactionItemResponse.fromDomain(created)
}
RepositoryImpl: domain ⇄ JPA
@Component
class TransactionRepositoryImpl(...)
    : TransactionRepository {
  override fun save(t: Transaction): Transaction {
    val saved = jpaTransactionRepository
        .save(t.toEntity())
    return saved.toDomain(t.category)
  }
}
